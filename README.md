# Amin player

This personal Android TV app opens FarsiLand with large Persian controls and a gold highlight that moves with the remote. The Android TV launcher tile is named **Amin player** and has a teal play symbol.

The latest version is **1.37 (versionCode 38)**: a lighter startup intro — the Amin Player mark appears as a still dark mould, molten gold rises inside it, and when it is full one heavy hammer strike sounds and the mark becomes polished gold (about 2 s, native 2D, the strike timed from the audio output itself). The app is about 5 MB lighter than 1.36. Version 1.36 had a new startup intro rendered as a 3D film — a great war maul strikes glowing metal on an anvil and a golden shield bearing the Amin Player mark and name rises from the anvil and cools to gold (played with the TV's hardware video decoder; skip with any button; switch off under **تنظیمات**). Version 1.35 added two separate VPN buttons at the top-left of the home screen — **VPN** (red «VPN قطع», amber «در حال اتصال», green «VPN وصل»; one press connects, cancels or disconnects) and **تنظیمات VPN** (settings only). Connect tries every VPN saved on that TV, personal ones first and free ones after, and turns green only when Farsiland and its video server answer through the tunnel. VPN settings have separate sections for personal V2Ray/Xray profiles, Kerio (Android's built-in IKEv2/IPsec, Android 11+), free methods (FreeSocks and free links) and Psiphon (not yet available). Every profile is encrypted and kept on that TV only. A new startup intro, **The Golden Forge**: a hammer strikes glowing metal on an anvil, sparks fly and the metal becomes the gold Amin Player mark, with a new original hammer-on-anvil sound. Version 1.34 brought a redesigned VPN screen in the app's theme with an easy free FreeSocks key, **☰ همه قسمت‌ها** (All Episodes) in the player, and a branded loading screen between pages. Since 1.33 the app opens with a short startup intro: the new forged-gold play mark forms on charcoal under a warm light sweep and lands with one anvil impact, while the home page loads underneath; both can be switched off under **تنظیمات**. The launcher icon and TV banner use the same mark. Version 1.32 brought a redesigned interface: three themes (**سینمای طلایی**, the default, **شب فیروزه‌ای** and **انار مخملی**), one icon set for the menu, large landscape Continue Watching cards, rotating recommendations and cinematic film and series pages. Since 1.31 the VPN file can also come from Google Drive: on the TV choose **انتخاب فایل از Google Drive با تلفن**, scan the QR with the phone, sign in to Google in the phone browser and pick the file from any folder. The TV asks before saving it, and the VPN still connects only when you choose Connect. Video quality is manual (1.30): playback starts at the lowest quality the site offers and never changes by itself; choose a resolution under **کیفیت** (Quality). The pick stays for the next and previous episodes until you leave the player. Pre-roll ads from Google's ad services are skipped (1.29), and slow pages get up to two minutes before Retry (1.28). HTTPS FarsiPlex/Buzz playback, original forms and session cookies, themes, VPN and the updater are preserved. Download [Amin-player-38.apk](https://github.com/Skyspiriit/Amin-Player/releases/download/v1.37/Amin-player-38.apk) from the [v1.37 release](https://github.com/Skyspiriit/Amin-Player/releases/tag/v1.37). The APK targets **ARMv7 (armeabi-v7a)**, the Xiaomi box architecture.

## Install on a Xiaomi TV Box

1. Copy `Amin-player-38.apk` from the [Amin player release](https://github.com/Skyspiriit/Amin-Player/releases/tag/v1.37) to a USB drive and insert it into the TV box.
2. Open the APK from a file manager on the box. If Android prompts you, allow this file manager to install apps, then choose **Install**. On some Xiaomi models the permission is under **Settings → Apps → Security & restrictions → Install unknown apps**. The exact menu varies by model. [Xiaomi installation help](https://www.mi.com/global/support/faq/details/KA-06364/)
3. Open **Amin player** from **Apps** on the TV home screen. You can turn the file manager's install permission off once installation is complete.

### Install from a computer on the same Wi-Fi

1. On the box, open **Settings → System → About** or **Settings → Device Preferences → About**. Select **Android TV OS build** or **Build** seven times with the remote. Some older Mi Boxes use the product model entry. [Xiaomi developer options](https://www.mi.com/my/support/article/KA-07022/) · [Older Mi Box settings](https://www.mi.com/global/support/article/KA-06513/)
2. Open **Developer options** and enable **Wireless debugging** if available. Choose **Pair device with pairing code**. Use the address and code shown on that screen for `adb pair IP:PAIRING_PORT`. If manual connection is needed after pairing, run `adb connect IP:DEBUGGING_PORT` with the address on the main Wireless debugging screen. [Android wireless debugging](https://developer.android.com/tools/adb?hl=en#connect-to-a-device-over-wi-fi)
3. On older boxes with **ADB debugging**, look under **Developer options** or **Account & security**. If the box accepts ADB over Wi-Fi, use its local IP from **Settings → Network & Internet** and approve the connection prompt on the TV. If the model only makes ADB available over USB, use the USB-drive installation steps above. [Xiaomi ADB help](https://www.mi.com/global/support/article/KA-06513/)
4. Once the device is connected, install or update the app:

```text
adb install -r --user 0 Amin-player-31.apk
```

## Watch with the remote

1. Use **Left/Right** to choose a poster and **Up/Down** to change rows. Press **OK** to open the highlighted item.
2. A series opens to its poster, synopsis and playback actions. Choose **پخش** (Play) to start the first episode or **ادامهٔ پخش** (Resume) to continue watching. Use **همه قسمت‌ها** (All Episodes) to open the episode picker. The season and episode numbers increase from right to left. **Back** closes the picker and returns to the series overview. If a previous episode exists, **قسمت قبلی** opens that episode.
3. Playback starts automatically in fullscreen, including Continue Watching and previous/next episodes. **Back** leaves fullscreen; pausing, resuming or changing quality then preserves that choice. Playback starts at the lowest quality the site offers. Select **کیفیت** (Quality) in the player and choose a resolution; the one playing is marked. The video briefly reloads at the new quality and continues from the same position. The app never changes quality by itself, so lower it by hand if the video keeps stopping to load. The choice stays for the next and previous episodes; anything started again from Home, an episode or movie screen, or after reopening the app begins at the lowest quality. **Up** from the player buttons opens the timeline, even when the controls have faded. **Down** returns to the player buttons. Outside fullscreen, another **Up** from the timeline reaches the top menu. With the timeline selected, use **Left/Right** to seek or hold either arrow to move faster. Separate ten-second seek buttons are no longer shown.
4. An episode opened from the homepage, a list or Back shows one screen: the episode title, a small centred preview, and three buttons: **پخش** (Play), **همه قسمت‌ها** (All Episodes), and **قسمت قبلی** (Previous Episode, when there is one). The rest of the website page is hidden and the screen does not scroll. Press **Back** to exit fullscreen and again to return to this episode screen. Back restores the episode you selected when you return to the series list. Use **خانه** in the top menu to go home.
5. Select the **جستجو** (Search) bar to open the built-in Persian keyboard. Use the arrows and **OK** to choose letters. Choose **English** to change the keyboard and **جستجو** below the keys to submit.
6. Slow page loads wait up to two minutes and show a Persian waiting explanation after 30 seconds. If a page fails to load, choose **تلاش دوباره** to retry.
7. **ادامهٔ تماشا** (Continue Watching) shows up to five recent movies and series as large landscape cards, three per screen, with a thin bar of the saved position; the focused card shows **▶ ادامهٔ پخش**. Below it, **پیشنهادها** shows four titles from the site at a time and changes group about every 12 seconds while the top menu is focused; it stops while you browse it, and Left/Right at its ends move to the next or previous group. Open a Continue Watching card and choose **▶ پخش** (Play) or **✕ حذف از ادامه پخش** (Remove). Removed titles disappear from the row and can return when you watch them again. At the end of an episode, the next episode starts after five seconds. If a new season is available, its first episode starts after the same countdown. Press **OK** to start immediately or choose **بعداً** or **Back** to cancel.
8. A movie opens to one screen with its poster, title, year, a short synopsis, **پخش** (Play) and the heart. While a movie or episode plays, only the video, its controls and the top menu are shown; the rest of the website page is hidden and the screen does not scroll.
9. While an episode plays, the player buttons include **◀ قسمت قبلی** (Previous episode), **❚❚ مکث / ▶ پخش** (Pause/Play) and **قسمت بعدی ▶** (Next episode). Previous and Next appear only when that episode exists.
10. Choose **تنظیمات** (Settings) in the top menu on the homepage. **انیمیشن آغاز برنامه** and **صدای آغاز برنامه** switch the startup intro and its sound (both on by default; the sound follows the TV's media volume and is silent when muted). The same dialog picks one of three themes: **سینمای طلایی** (charcoal and gold, the default), **شب فیروزه‌ای** (navy and turquoise) or **انار مخملی** (burgundy, cream and copper). A theme saved by an older version opens as the closest of the three. The choice is saved on the TV and applies to every screen, including the player. Page animations are short and turn off when Android's reduced-motion setting is on; the startup intro always plays in full.
11. Select the heart on a movie or series detail page to add or remove it from Favorites. Open **علاقه‌مندی** from the top menu to see saved titles. Favorites and playback progress are stored separately on the TV.

> با دکمه‌های جهت‌دار روی فیلم، سریال یا قسمت بروید و **OK** را بزنید. برای تماشا **پخش** را انتخاب کنید. با دکمهٔ **بازگشت** ابتدا از تمام‌صفحه خارج می‌شوید و بعد به صفحهٔ قسمت برمی‌گردید.

## Optional VPN and private import

1. Choose **VPN** in the top menu on the homepage; it shows whether the VPN is off, connecting or connected. Android explains and requests VPN permission when needed. The VPN starts only after you explicitly choose Connect. Android supports one active VPN at a time.
2. Choose **انتخاب فایل از Google Drive با تلفن** (Google Drive on your phone), or the existing **دریافت خصوصی از تلفن یا رایانه** (private file import). Both open the TV’s temporary QR receiver. Connect the iPhone or computer to the same Wi-Fi as the TV. Scan the QR with the iPhone Camera and tap its link, or type the displayed address in a browser.
3. The page uses a temporary local HTTPS certificate. If the browser displays a certificate warning, compare its SHA-256 fingerprint with the TV before deciding to continue. No certificate installation is required.
4. Enter the separate eight-digit TV code. For Drive, choose **انتخاب از Google Drive**, sign in with your own Google account in the phone browser, and use Google Picker to browse your accessible folders and select an existing file. The Picker opens on **Google Drive** (your own Drive) with all its folders; files shared with you and shared drives are on the other tabs (on a phone, under **بیشتر**, More). No particular folder name, filename or extension is required. Return to the private TV page and choose **ارسال به تلویزیون**. Alternatively, choose a file already in the phone’s Files app, including iCloud or a configured Drive provider. Content must be UTF-8, nonempty, no larger than 1 MiB, and contain a private HTTPS subscription link, compatible VLESS links, a Base64 VLESS subscription, or supported Xray JSON.
5. Send the file and approve **Save** with the TV remote. Existing VPN settings change only after this approval. Choose Connect separately. Choose Disconnect to return to ordinary internet routing.

The QR contains only the temporary page address. The file is transferred directly over the local network, held in memory until TV approval, and then encrypted in the app's private no-backup storage using Android Keystore. The receiver closes after a saved import, ten minutes, five incorrect codes, Back, or leaving its screen. Pairing codes, profiles, and private subscription links are not included in the source or release. Each person can import their own compatible FreeSocks subscription link or exported profile on their own device; a bare account number is not a VPN profile.

The engine supports VLESS with TLS or REALITY. Use your own provider subscription; none is bundled. Provider availability and account limits remain controlled by that provider. The VPN covers the device, including separate playback apps, while connected. No always-on or lockdown setting is enabled by default.

The old TV-side broad Drive authorization and folder queries have been removed. The actual recorded Xiaomi error was **400 invalid_request**, stating that the Android OAuth client was not permitted to request the broad read-only scope. The current Android client’s package and original SHA-1 were checked in Google Cloud; registration alone did not fix that method. The new companion uses Google’s supported browser token model and Picker, requesting only **drive.file**. Google Picker supplies the explicit existing-file selection step; a sign-in alone is not treated as selecting a file. No whole-Drive listing or fixed-folder check remains. [Google Picker for web apps](https://developers.google.com/workspace/drive/picker/guides/web-picker) · [Per-file scope](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

The static companion is hosted on this repository’s GitHub Pages. A web OAuth client authorizes only the companion’s HTTPS origin. Its public browser key is restricted to the Picker/Drive APIs and the companion/Google Picker websites. No OAuth client secret is used. OAuth access tokens stay in phone-browser memory and are sent only to Google, never to the TV, URLs, QR payloads, GitHub or a relay. Only the selected file bytes cross an origin-, popup-, nonce- and expiry-checked message channel to the private TV page. Upload still requires its pairing code and explicit TV confirmation. Google sign-in, missing-file, expired-access, cancellation, network and size errors have Persian messages.

Each person signs in to their own account. The browser model obtains a short-lived access token for the current import, stores no refresh token and requests no offline access; an expired token requires a fresh button press. The local TV session still lasts ten minutes. Revoking Google access or cancelling an import leaves the TV’s saved configuration unchanged. If a browser blocks popups or Google is unavailable, local file import remains available. [Google browser token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model)

## Update

If you are installing for the first time or updating from a version older than 1.3, install the latest APK from the TV file manager or with the command above. It uses the original package and signing key, so it can update earlier versions in place and keep their data and cookies.

From 1.3 onward, Amin player checks GitHub when opened. When it finds a newer signed release, it downloads it and shows **نسخهٔ تازه آماده است** on the homepage. Choose **نصب به‌روزرسانی** (Install update) or **بعداً** (Later). If the app needs installation permission, allow **Amin player** in the profile where it is running. On the main TV profile, choose the entry without a briefcase badge: Android keeps this permission separately for each profile, and allowing the briefcase entry does not allow updates in the main profile. From 1.19, if the permission is still off when you return, the app explains this again and offers **باز کردن تنظیمات** instead of opening Android's installer, which would only show “not allowed to install unknown apps from this source”. Press **Back** to return and choose **Update** or **Install** on Android’s confirmation screen. Version 1.11 can resume a verified download after a restart or when the website or GitHub is temporarily unavailable. If the older updater is stuck, install 1.11 once over the existing app to keep its data. [GitHub releases](https://github.com/Skyspiriit/Amin-Player/releases) · [Android installer permissions](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls())

For future releases, increment both `versionCode` and `versionName` in `app/build.gradle.kts`, build with the original signing key, and publish a stable GitHub release. Name the attached APK `Amin-player-<versionCode>.apk`. The app checks the APK’s version, package name, signer and GitHub’s SHA-256 checksum before offering it. Version 1.37 uses versionCode 38, so its asset is Amin-player-38.apk. The current updater accepts APKs up to 32 MiB; native libraries are compressed and the primary release APK targets the tested ARMv7 architecture to fit that limit. The updater implementation itself is unchanged. [GitHub release management](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository) · [Android app signing](https://developer.android.com/studio/publish/app-signing)

## Build from source

Open this project directory in Android Studio with support for Android Gradle Plugin 8.13. Use JDK 17, Android SDK Platform 35 and Android SDK Build-Tools 35.0.0. The project includes Gradle Wrapper 8.13. From the project directory, use the command below on Windows, or `./gradlew assembleDebug` on macOS and Linux. [Android Gradle Plugin compatibility](https://developer.android.com/build/releases/agp-8-13-0-release-notes)

```powershell
.\gradlew.bat -PaminTargetAbi=armeabi-v7a assembleDebug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`. Omit `aminTargetAbi` for all supported ABIs or set it to `arm64-v8a`, `x86`, or `x86_64` for another device. Keep the same signing keystore for future updates and increment `versionCode` in `app/build.gradle.kts` when making a new version. The source archive excludes build caches, signing keys, personal diagnostics, and private VPN files. Debug signing on a new machine generates a different identity unless the original key is supplied privately.

## Implementation and limits

- The Kotlin activity hosts FarsiLand and its supported playback sites, `farsiland.buzz` and `farsiplex.com` (including their `www` variants). It keeps the site's own catalogue, search form, sign-in and playback handoff. The app uses the player controls and the video already present on the page. No public API or direct stream URL is required. [FarsiLand home](https://farsiland.com/home)
- Directional focus uses the position of visible page controls, with automatic scrolling through poster rows and focus restoration when navigating Back. The activity handles loading, reload, native fullscreen and the player’s return path.
- The app uses its own WebView cookies. If an account is needed, sign in within the app and use the site's **Remember Me** option. Session expiry is controlled by the website. The tested public episode streamed while signed out. Some account providers may require a separate browser.
- Continue Watching, the app timeline, and next-episode playback use the main player. If a video is in a cross-origin frame, OK passes remote focus into the frame. Its controls depend on that provider's keyboard support. Up, Down, or Back returns focus to the app. Use the site's alternate player link when offered if the default player fails.
- The homepage and playback handoff depend on FarsiLand’s current layout and domains. Catalogue titles may use the site's romanized spelling. Codec support, site availability and the TV keyboard's available languages depend on the box and its installed WebView.
