## Android TV comparison

The representative series was [The Forbidden Fruit](https://farsiland.com/tvshows/the-forbidden-fruit/), with 31 episode links in the sampled catalogue and a 728-character synopsis in the rendered overview. Each PNG is an unedited Android framebuffer capture. The emulator used Android TV 14 with WebView 113.0.5672.136. Its Home progress entries are from local QA playback. The screenshot filenames identify the configuration.

The series shell specifies `width=device-width, initial-scale=1`; `MainActivity` enables the WebView wide viewport and overview settings. The CSS reduces the summary from five lines to four at 430 CSS px of viewport height, then to three at 330 CSS px. The lower breakpoint was read from source. [WebView settings](../../app/src/main/java/com/enigma/farsilandtv/MainActivity.kt#L107) · [Breakpoints](../../app/src/main/assets/tv.css#L538)

**Physical Xiaomi evidence.** The reachable MiTV-AFKR0 reported Android 11, 1920×1080, 320 dpi, no recorded font-scale override, and WebView 157.0.8103.40. The installed APK SHA-256 matched the v1.16 release. Its active provider page reported a 960×540 CSS viewport and DPR 2 while a video was playing. No diagnostic navigation or screenshots interrupted that session. Panel overscan, detail-screen layout, and the route behind the report remain unmeasured on the physical device.

## Cache and focus

- **Confirmed by emulator.** The sample series retained the same overview, poster geometry, and screen height on a new navigation with Chromium’s cache disabled. The series request trace contains an app `Document` and a separate successful `Fetch` for provider HTML. This run gives no evidence that Chromium cache caused the reported appearance. [Cache-disabled screenshot](screenshots/09-tv1080-series-cache-disabled.png)
- **Confirmed by emulator.** D-pad focus stayed on app controls in the canonical series overview and picker. On the episode route the original Play control intentionally remained focusable. Ratings and sharing rendered lower in the episode document. Their complete focus order was outside this check.
- **Not yet verified.** An alternative route or redirect may omit interception because it depends on a recognized initial main-frame GET. A movie, an episode watch page, or a resumed route can already lead to a different visible layout through normal code. The installed hash rules out an older APK on the sampled Xiaomi profile at inspection time.

The observation files record public test paths, DOM visibility flags, geometry, status codes, and JavaScript exception counts. WebView reported zero uncaught JavaScript exceptions during both capture runs. The observed Logcat updater message was `AminUpdater: Installed version is up to date`. See [1080p observations](tv1080-observations.json) and [720p observations](tv720-observations.json).
