حریم خصوصی انتخاب فایل

انتخاب فایل در Google Picker انجام می‌شود. این برنامه فقط دسترسی drive.file را درخواست می‌کند؛ این اجازه مربوط به فایل‌هایی است که شما برای برنامه انتخاب می‌کنید، نه خواندن تمام Drive. برنامه از این اجازه فقط برای دریافت همان فایل انتخابی استفاده می‌کند و فایلی را در Drive ایجاد، ویرایش یا حذف نمی‌کند.

اجازهٔ موقت Google و محتوای فایل در حافظهٔ مرورگر تلفن باقی می‌مانند. اجازه در تلویزیون، حافظهٔ دائمی مرورگر، نشانی صفحه یا کد QR قرار نمی‌گیرد. تنها محتوای فایل انتخابی به صفحهٔ خصوصی تلویزیون در همان مرورگر تحویل داده می‌شود؛ ارسال به تلویزیون و ذخیرهٔ نهایی به تأیید شما نیاز دارند.

سایت روی GitHub Pages است. میزبانی سایت می‌تواند اطلاعات معمول درخواست وب مثل نشانی اینترنت و زمان بازدید را پردازش کند؛ ما فایل تنظیمات، پیوند خصوصی اشتراک یا اجازهٔ Google را به GitHub یا یک سرور واسط ارسال نمی‌کنیم. برنامه آمارگیری یا تبلیغات این صفحه را اضافه نمی‌کند.

تا زمانی که روی تلویزیون «ذخیره» را تأیید نکنید، تنظیمات VPN قبلی جایگزین نمی‌شود. تلویزیون محتوای فایل را بررسی و در حافظهٔ رمزگذاری‌شدهٔ برنامه نگه می‌دارد. اتصال VPN یک کار جداگانه است.

اجازهٔ Google را می‌توانید از صفحهٔ اتصال‌های حساب Google لغو کنید. اگر دریافت منقضی شد، دسترسی لغو شد یا فایل قابل استفاده نبود، یک دریافت جدید روی تلویزیون باز کنید؛ روش انتخاب فایل از خود تلفن هم همیشه باقی می‌ماند.

Amin Player uses Google's drive.file scope and Google Picker to read only files explicitly selected by the user. Access tokens and file bytes stay in browser memory. No OAuth client secret is used. The hosting provider receives ordinary static-page requests, never the selected configuration or access token. The user approves the final encrypted import on the TV. No analytics are added.
